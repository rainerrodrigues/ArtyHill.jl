Code generation

Two routes produce a library that a C/C++ real-time target can call.

compile_controller (StaticCompiler.jl)juliac_build (JuliaC.jl)
Julia1.10 / 1.11≥ 1.12
Runtimenone: depends on libc onlytrimmed libjulia (bundle it with bundle=)
Language subsetno GC allocation, no exceptions, raw pointersmost of Julia, including ArtyHill's own types

StaticCompiler

using ArtyHill, StaticCompiler, StaticTools
pd(u::Ptr{Float64}, x::Ptr{Float64}, y::Ptr{Float64}) =
    (unsafe_store!(u, -40unsafe_load(y, 1) - 12unsafe_load(y, 2)); Int32(0))
compile_controller(pd, (Ptr{Float64}, Ptr{Float64}, Ptr{Float64}), "build", "pd")

juliac

Write a file with Base.@ccallable entry points (see examples/juliac_controller.jl, which wraps a LimitedController), then:

using ArtyHill, JuliaC
juliac_build("examples/juliac_controller.jl"; output="build/libpd_limited")
